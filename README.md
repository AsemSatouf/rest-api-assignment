## Project Description

This project is a RESTful API frontend application built using Angular 20.

The application consumes the CheapShark API to:
- Display game deals
- Search for games
- Show game details
- Display game stores

Used API:
https://www.cheapshark.com/api/1.0

---

## Technologies Used

- Angular 20
- TypeScript
- REST API
- HttpClient
- Angular Routing

---

## API Endpoints Used

- /deals
- /games?title=
- /games?id=
- /stores

---

## How to Run the Project

1. Install dependencies

```bash
npm install
```

2. Run the project

```bash
ng serve
```

3. Open browser

```text
http://localhost:4200
```
